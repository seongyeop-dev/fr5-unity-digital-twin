# 04. 데이터 흐름

## 메뉴 선택과 제조 흐름

```text
입력 대기
→ GetDI(0,0)·GetDI(1,0) 확인
→ 메뉴 1·2 분기
→ 컵 작업 위치 접근
→ 그리퍼 파지
→ 메뉴별 펌프 위치 순차 방문
→ LIN 하강
→ WaitMs 작업 대기
→ LIN 상승
→ 컵·뚜껑 작업
→ Spiral 혼합
→ 완성 컵 배치
→ Home 복귀
→ 다음 입력 대기
```

## Pick & Place 흐름

```text
Home
→ 대상물 접근
→ LIN 파지 위치 이동
→ 그리퍼 닫기
→ Home 경유
→ 배치 위치 이동
→ 그리퍼 열기
→ Home 복귀
→ 반대 방향 작업 반복
```

## 소스 연결

| 단계 | 구현 근거 |
|:---|:---|
| 메뉴 입력 | `GetDI(0,0)`, `GetDI(1,0)` |
| 메뉴 분기 | `loop1 == 1`, `loop1 == 2` |
| 주요 위치 이동 | `PTP(...)` |
| 작업 위치 접근 | `Lin(...)` |
| 펌프 위치 대기 | `WaitMs(1000)` |
| 컵·뚜껑 작업 | `MoveGripper(...)` |
| 혼합 | `Spiral(...)` |
| 작업 종료 | `PTP(team_pHome, ...)` |

`web_point.db`의 작업 포인트는 Lua에서 사용하는 이름과 연결되며, 실제 좌표는 교육 장비의 Workcell 배치에 종속됩니다.
